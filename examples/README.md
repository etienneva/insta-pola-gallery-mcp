# Client configuration examples

| Client | File | Where to put it |
|---|---|---|
| VS Code | [`vscode-mcp.json`](vscode-mcp.json) | `.vscode/mcp.json` in your workspace |
| Cursor | [`cursor-mcp.json`](cursor-mcp.json) | `~/.cursor/mcp.json` |
| Claude Code | — | `claude mcp add --transport http insta-pola https://www.insta-pola.com/mcp/claude` |

These follow each client's documented format. On first use, the client opens the Insta-Pola sign-in page (OAuth with dynamic client registration).
